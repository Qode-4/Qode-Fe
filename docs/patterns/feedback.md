# 패턴: 피드백

> 성공한 결과가 화면에 바로 보이면 조용히. 안 보이거나, 보던 화면이 사라지면 토스트로 한 줄.

## 언제 이 패턴을 마주치나

- 복사·공유·초대처럼 결과가 지금 화면 밖에서 일어날 때
- 이름 바꾸기·삭제·만들기처럼 결과가 목록에 바로 반영될 때
- 지금 보던 채팅·프로젝트를 지우거나 나가서 화면이 바뀔 때

## 결정 트리

```
성공한 결과가 지금 화면에서 바로 보이나?
├─ 예 (목록에서 사라짐·이름이 바뀜·새 항목으로 이동) ─── 알리지 않음 — 화면 변화가 곧 피드백
├─ 아니오 (클립보드·다른 채팅방·다른 사람에게 감) ────── 성공 토스트
└─ 보던 화면이 사라짐 (보던 채팅·프로젝트 삭제·나가기) ── 성공 토스트 — 왜 화면이 바뀌었는지

모달이 계속 열려 있는 채로 끝나면 ─────────────────── 모달 안 InlineAlert tone="success"
```

## 옵션별 세부

### 알리지 않음

- 이름 바꾸기(사이드바·헤더·모달), 새 팀 채팅(그 채팅으로 이동), 멤버 내보내기(목록에서 사라짐), 공유 취소(카드가 사라짐), 사이드바에서 **다른** 채팅 삭제

### 성공 토스트 — `toast.success`

- 복사, 팀 채팅에 공유, 멤버 초대
- **보던** 채팅·프로젝트를 삭제·나가기·방장 넘기고 나가기 — `activeChatId`/`selectedProjectId` 와 같을 때만

### 모달 안 success

- 초대 링크 다시 만들기, 새 프로젝트의 초기 동기화 진행

## 문구

- 담담한 과거형 **"~했어요"**: `복사했어요` · `팀 채팅에 공유했어요` · `‘z’ 채팅을 삭제했어요`
- 대상이 있으면 이름을 넣는다. 느낌표·이모지·"성공!" 금지.

## Do / Don't

| Do                                          | Don't                                     |
| ------------------------------------------- | ----------------------------------------- |
| 멤버를 내보내면 목록에서 사라지는 것으로 끝 | 목록에서 사라지는데 "내보냈어요" 토스트도 |
| 보던 채팅을 지우면 "‘z’ 채팅을 삭제했어요"  | 화면이 바뀌는데 아무 설명 없음            |
| `복사했어요`                                | `복사 완료! 🎉` · `복사되었습니다`        |

## Qode 에서의 실제 결정 기록

- 2026-09-26: 같은 "삭제"인데 팀 채팅만 토스트, 개인 채팅·프로젝트는 무응답이던 것을 트리로 정리. 보던 것을 지울 때만 알리기로 하고 개인 채팅·프로젝트 삭제에 토스트 추가, 팀 채팅 삭제·나가기는 보던 채팅일 때만. 목록에 바로 보이는 멤버 내보내기·공유 취소 토스트는 제거. 복사 토스트 문구를 "~했어요"로 통일.
