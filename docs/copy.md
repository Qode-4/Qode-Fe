# Quire Copy — 화면 문구 카탈로그

> 화면에 보이는 한국어 문구의 기준. 🤖 표시는 `yarn tokens:check` 가 자동으로 잡는다.
> 상위: [`SYSTEM.md`](../SYSTEM.md) · 상황별 결정: [`docs/patterns/`](./patterns/README.md) · 컴포넌트: [`docs/registry.md`](./registry.md)

## 1. 기본

- **해요체로 통일한다.** 🤖 `~습니다`·`~합니다`·`~입니다`·`~됩니다` 는 쓰지 않는다.
  - 예외: 개발자만 보는 메시지(`throw new Error(...)`), AI 가 쓴 답변 본문, 서버가 내려준 원문.
- 짧고 구체적으로. 한 문장에 한 가지.
- 말줄임표는 **`…` 한 글자**. 🤖 마침표 3개(`...`) 금지. 입력창 placeholder 에는 붙이지 않는다.
- `~해주세요` 는 붙여 쓴다(지금 표기 유지). `~해 보세요` 처럼 권유는 띄어 쓴다.
- 느낌표·이모지·과장("성공!", "완료! 🎉")은 쓰지 않는다.

## 2. 상황별 톤

| 상황         | 형태                                   | 좋음                                                                     | 피함                               |
| ------------ | -------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------- |
| 성공(토스트) | 담담한 과거형 **"~했어요"**            | `복사했어요` · `‘z’ 채팅을 삭제했어요`                                   | `복사되었습니다` · `복사 완료!`    |
| 실패         | **무엇을 못 했는지 + 다음 행동**       | `채팅 목록을 불러오지 못했어요.` + [다시 시도]                           | `오류가 발생했습니다.`             |
| 시스템 오류  | 쉬운 말로, 원인이 있으면 원인          | `답변이 끝나기 전에 연결이 끊겼어요.`                                    | `스트리밍 연결이 종료되었습니다.`  |
| 확인(질문)   | 대상을 밝힌 질문 + 결과 동사 버튼      | `‘z’ 채팅방을 삭제할까요?` [삭제]                                        | `정말 삭제하시겠습니까?` [확인]    |
| 확인(설명)   | 무엇이 사라지고 누구에게 영향이 가나   | `채팅방과 모든 대화가 삭제되고, 참여자 전원이 더 이상 볼 수 없어요.`     | `접근할 수 없게 됩니다.`           |
| 로딩         | **"~를 불러오는 중…"** — 대상을 넣는다 | `멤버를 불러오는 중…` · `다시 연결하는 중…`                              | `로딩 중` · `불러오는 중입니다...` |
| 빈 상태      | 무엇이 없는지 (+ 다음 행동)            | `아직 채팅이 없어요.` / `＋ 를 눌러 코드에 질문해 보세요.`               | `데이터가 없습니다.`               |
| 입력 검증    | 무엇이 틀렸는지 / 어떻게 고치나        | `이메일 형식이 올바르지 않아요.` · `이미 쓰고 있는 채팅방 이름이에요.`   | `유효하지 않은 입력입니다.`        |
| 비활성 이유  | 왜 안 되는지                           | `아직 지원하지 않는 기능이에요.` · `팀 채팅은 아직 읽기만 할 수 있어요.` | `권한이 없습니다.`                 |

- 실패 문구의 "못 했어요"와 "할 수 없어요"를 구분한다: 시도했는데 실패 → `불러오지 못했어요`, 원래 안 되는 것 → `해제할 수 없어요`.
- 오류 문구를 새로 만들기 전에 `api/errorMessages.ts`(`friendlyErrorMessage`)·`lib/sync-errors.ts`·`lib/response-errors.ts` 에 이미 있는지 본다.

## 3. 용어집

| 쓴다            | 쓰지 않는다         | 뜻                                                                                                       |
| --------------- | ------------------- | -------------------------------------------------------------------------------------------------------- |
| **팀 채팅**     | 🤖 팀채팅           | 여러 사람이 함께 쓰는 채팅방                                                                             |
| **내 채팅**     | —                   | 나와 AI 만의 채팅 목록(사이드바 제목). 새 채팅 기본 이름 `새 개인 채팅` 은 서버에 저장되는 값이라 그대로 |
| **저장소**      | 🤖 레포지토리, 레포 | GitHub 저장소 (GitHub 한국어 UI 표기)                                                                    |
| **방장 넘기기** | 🤖 양도             | 팀 채팅방 방장을 다른 참여자에게                                                                         |
| **멤버**        | —                   | **프로젝트**에 속한 사람                                                                                 |
| **참여자**      | —                   | **팀 채팅방**에 들어와 있는 사람 — 멤버와 섞어 쓰지 않는다                                               |
| **동기화**      | 싱크                | GitHub 저장소 코드를 가져와 분석하는 것                                                                  |
| **참조 코드**   | 출처                | AI 답변이 근거로 든 코드 위치 (`SourceList`). `연결된 소스`(프로젝트에 연결한 저장소)와는 다른 말        |
| **공유 카드**   | —                   | 개인 채팅 답변을 팀 채팅에 올린 카드                                                                     |

- 버튼은 실행 결과를 말한다: `동기화` · `다시 시도` · `새 채팅` · `이름 바꾸기` · `팀 공유` · `나가기` · `삭제`. "확인" 금지.
- 같은 동작은 흐름 전체에서 같은 이름으로 부른다(메뉴 항목 = 모달 제목 = 버튼).

## 4. 결정 기록

- 2026-09-26 (Phase F): 화면 문자열 591개 중 습니다체 88 · 해요체 146 이 섞여 있던 것을 해요체로 통일. 말줄임표 `...` 16곳을 `…` 로. 팀채팅→팀 채팅, 레포지토리→저장소, 양도→방장 넘기기. 멤버/참여자는 뜻이 달라 유지. `해주세요` 띄어쓰기는 바꿀 이득이 없어 유지. 서버가 내려주는 오류 원문은 이번 범위 밖.
